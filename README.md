# سامانه مدیریت داخلی

اپلیکیشن Flask با ذخیره‌سازی داده در فایل‌های JSON (بدون دیتابیس)، رابط کاربری کاملاً فارسی و راست‌چین با دو تم روشن/تیره.

## ساختار پروژه

```
project/
├── app.py                  # اپلیکیشن اصلی Flask (نقطه ورود Gunicorn: app:app)
├── karzar_login.py         # ورود به karzar.net با Playwright و ذخیرهٔ پروفایل کروم هر اکانت
├── requirements.txt
├── data/
│   ├── users.json          # داده کاربران (کاربر پیش‌فرض ادمین)
│   ├── accounts.json       # اکانت‌های کارزار (نام، شماره/ایمیل، مسیر پروفایل)
│   ├── profiles/<name>/    # پروفایل کروم هر اکانت (gitignore)
│   └── login_sessions/     # وضعیت فرایندهای ورودِ در حال انجام (gitignore)
├── templates/
│   ├── base.html           # قالب پایه: سایدبار، هدر، تم، فلش‌مسیج‌ها
│   ├── login.html
│   ├── dashboard.html
│   ├── users.html          # مدیریت کاربران (فقط ادمین)
│   ├── accounts.html       # مدیریت اکانت‌های کارزار (لیست + مودال افزودن/حذف)
│   ├── signatures.html     # ثبت امضا (فقط رابط کاربری)
│   └── 404.html
└── static/
    ├── css/style.css       # افکت‌های شیشه‌ای، انیمیشن، اسکرول‌بار سفارشی
    ├── js/main.js          # تم، سایدبار موبایل، مودال‌ها، جستجو/فیلتر
    └── js/accounts.js      # فرایند افزودن اکانت کارزار (ارسال کد → ورود)
```

## اجرا

```bash
pip install -r requirements.txt
playwright install chromium            # مرورگر مورد نیاز برای ورود به کارزار
python app.py                      # اجرای توسعه روی پورت 5000

# یا برای production:
gunicorn app:app -b 0.0.0.0:8000
```

## ورود پیش‌فرض

| نام کاربری | رمز عبور |
|---|---|
| `admin` | `admin123` |

> پیشنهاد می‌شود پس از اولین ورود، رمز عبور ادمین از طریق کد یا فایل `data/users.json` تغییر داده شود، و مقدار `SECRET_KEY` در `app.py` (یا از طریق متغیر محیطی) برای محیط Production تنظیم شود.

## نکات

- تمام داده‌ها در پوشه `data/` به‌صورت JSON نگهداری می‌شوند و با هر تغییر بازنویسی می‌شوند.
- امکان ثبت‌نام عمومی وجود ندارد؛ فقط ادمین از داخل بخش «مدیریت کاربران» می‌تواند کاربر (با نقش عادی) بسازد.
- «مدیریت اکانت‌ها»: با دکمهٔ «افزودن اکانت کارزار» نام اکانت و شماره/ایمیل را می‌گیرد، با Playwright وارد karzar.net می‌شود، کد ورود را از کاربر دریافت می‌کند و بعد از ورود موفق، پروفایل کروم را در `data/profiles/<name>` ذخیره می‌کند تا دفعات بعد بدون لاگین مجدد با همان session وارد کارزار شود.
- بخش «ثبت امضا» فعلاً فقط رابط کاربری (انتخاب اکانت + ارسال فرم) را پیاده‌سازی می‌کند؛ منطق پردازش واقعی بعداً اضافه خواهد شد.
